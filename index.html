Qwik: handlers run too late right after render()

Each box is its own client container, created with await render(host, <Demo />) in src/main.tsx. As soon as render() resolves, the script clicks the box's button with button.click().

The button's onClick$ calls ev.stopPropagation() (in a sync$), so the wrapper's onClick$ must never run. Expected for every box: "wrapper handler: 0".

With @qwik.dev/core 2.0.0-beta.37 every box shows OK. With 2.0.0-beta.38 through 2.0.0-rc.5, boxes #2 and #3 show BUG. Box #1 usually shows OK only because its render() had to load the component's code first, which gives Qwik time to finish its async container setup.

Clicking any box by hand later is fine: the handlers are only deferred in the short window right after a render().
